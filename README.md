# Poorya — Cyberpunk Research Portfolio

React + Vite portfolio website with a cyberpunk aesthetic.

## Local development

```bash
npm install
npm run dev
```

## Customize

- Put your portrait at `public/profile.jpg`.
- Replace `YOUR_EMAIL@example.com` in `src/main.jsx` with your real email.
- Replace the generic GitHub and LinkedIn links with your profiles.
- Update project descriptions and add links to verified publications.

## Publish on GitHub Pages

1. Create a public repository named `<your-username>.github.io`.
2. Push the files to the `main` branch.
3. In **Settings → Pages → Build and deployment**, choose **GitHub Actions**.
4. Wait for the deployment workflow to complete.

For a repository with another name, configure Vite's `base` option for the repository path.
